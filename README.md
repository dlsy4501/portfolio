# 임세윤 포트폴리오

AI·비전 엔지니어 지망 임세윤의 포트폴리오 웹 페이지입니다. 빌드 과정 없이 `index.html` 한 파일로 동작합니다.

## 배포 (GitHub Pages)

1. 저장소 Settings → Pages
2. Source: `Deploy from a branch`, Branch: `main` / `(root)` 선택 후 Save
3. 잠시 뒤 `https://dlsy4501.github.io/portfolio/` 에서 확인

## 구성

- `index.html`: 포트폴리오 전체 (프로젝트 내용은 파일 안 `PROFILE`, `PROJECTS` 데이터에 있음)
- `media/<프로젝트>/`: 프로젝트별 사진·영상 폴더 (`lumo`, `didim`, `haptic4d`, `squash`, `mercantis`, `sideimpact`, `yolov1`, `classify`, `aed`, `coldcache`, `bungbang`). 구조도 PNG도 여기에 있습니다. 폴더마다 README에 올리는 규칙이 적혀 있습니다.
- 화면 아래 "작성 메모 보이기"를 누르면 아직 채우지 못한 부분(사진·영상 자리, 확인 메모)이 보입니다. 기본값은 숨김입니다.
